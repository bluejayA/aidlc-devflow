# NFR 도메인 프리셋 가이드

> 프로젝트 CLAUDE.md에 `### NFR 기본 도메인` 섹션을 추가하면,
> `aidlc-nfr-requirements` Step 2(도메인 질문)에서 해당 값을 우선 적용한다.
> 스킬 수정 없이 프로젝트별 NFR 기본값을 설정할 수 있다.

---

## 사용법

프로젝트 CLAUDE.md에 아래 형식으로 추가:

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: [도메인명]
- [NFR 카테고리]: [기본값] ([조건])
```

nfr-requirements 스킬이 이 섹션을 감지하면:
1. Step 2(도메인 질문)을 스킵하고 지정된 도메인 적용
2. Step 5(기본값 제시)에서 지정된 수치를 우선 사용
3. 미지정 카테고리는 도메인+프로파일 기반으로 Claude가 추론

## 도메인별 프리셋 예제

### 클라우드/AI 인프라

API 서비스, AI 파이프라인, 플랫폼 서비스 등.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: 클라우드/AI 인프라
- 가용성: 99.9% (내부 서비스), 99.95% (고객 대면 API)
- 응답 시간: API 200ms (p95), 배치 작업은 제한 없음
- 확장성: 수평 확장 기본 (k8s 기반)
- 보안: 내부망 mTLS, 외부 API는 OAuth2/JWT
- 모니터링: Prometheus + Grafana 기본, 알림은 PagerDuty/Slack
```

### 사내 도구 / 백오피스

관리자 대시보드, 내부 운영 도구, 배치 처리 시스템 등.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: 사내 도구
- 가용성: 99.5% (업무 시간 기준)
- 응답 시간: 페이지 로드 1초 이내, API 500ms (p95)
- 확장성: 수직 확장 우선 (사용자 수 제한적)
- 보안: 내부망 기준, SSO 연동
- 모니터링: 로깅 필수, 알림은 이메일/Slack
```

### 이커머스 / 고객 대면 서비스

쇼핑몰, SaaS, 고객 포털 등.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: 이커머스
- 가용성: 99.95% (결제 경로 99.99%)
- 응답 시간: 페이지 로드 500ms, API 100ms (p95)
- 확장성: 수평 확장 필수, 트래픽 3배 버스트 대응
- 보안: PCI-DSS (결제), 개인정보보호법 준수
- 모니터링: APM + 실시간 대시보드, 결제 실패 즉시 알림
- 재해 복구: RPO 1시간, RTO 4시간
```

### 금융 / 핀테크

은행 시스템, 결제 게이트웨이, 투자 플랫폼 등.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: 금융/핀테크
- 가용성: 99.99%
- 응답 시간: 거래 처리 50ms (p99)
- 보안: 금융보안원 기준, 암호화 필수 (전송+저장), 감사 추적 전건
- 컴플라이언스: 전자금융거래법, 신용정보법
- 데이터 무결성: 트랜잭션 ACID 보장, 이중화 필수
- 재해 복구: RPO 0 (동기 복제), RTO 30분
```

### MVP / 프로토타입

빠른 검증이 목적인 초기 프로젝트.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: MVP
- 가용성: 99% (다운타임 허용)
- 응답 시간: 2초 이내 (체감 가능 범위)
- 보안: HTTPS + 기본 인증
- 모니터링: 에러 로깅만 (Sentry 등)
```

### 범용 (도메인 미정)

특정 도메인에 속하지 않는 프로젝트.

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: 일반
- 가용성: 99.9%
- 응답 시간: API 300ms (p95)
- 보안: OWASP Top 10 기준
- 모니터링: 구조화된 로깅 + 헬스체크
```

## 커스텀 카테고리 추가

8개 표준 카테고리 외에 프로젝트 특화 NFR을 추가할 수 있다:

```markdown
### NFR 기본 도메인
- 프로젝트 도메인: AI 파이프라인
- 가용성: 99.9%
- GPU 활용률: 배치 학습 시 80% 이상
- 모델 서빙 지연: 추론 100ms (p95)
- 데이터 파이프라인: 일 1회 이상 갱신, 누락률 0.1% 미만
```

Claude는 표준 8개 카테고리와 커스텀 항목을 모두 포함하여 NFR 문서를 생성한다.

## 프로파일과의 조합

CLAUDE.md의 도메인 프리셋은 **도메인 기본값**만 설정한다.
프로파일(MVP/소규모/중규모/대규모)은 nfr-requirements Step 3에서 사용자가 선택한다.

도메인 프리셋 + 프로파일 조합 시:
- 프리셋 수치가 프로파일 기본값보다 **높으면**: 프리셋 수치 유지 (도메인 요구사항이 더 엄격)
- 프리셋 수치가 프로파일 기본값보다 **낮으면**: 프로파일 기본값 적용 (운영 환경 요구사항이 더 엄격)
- 프리셋에 없는 카테고리: 프로파일 기본값으로 Claude가 추론
