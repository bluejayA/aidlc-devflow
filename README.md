# aidlc-pilot

AI-DLC(AI-Driven Development Life Cycle)를 Superpowers 스타일의 Skills 세트로 구현하는 파일럿 프로젝트.

## 배경

- [AWS Labs - aidlc-workflows](https://github.com/awslabs/aidlc-workflows): AWS가 제안한 AI 주도 개발 생명주기 방법론
- [obra/superpowers](https://github.com/obra/superpowers): Claude Code의 Skills 기반 개발 워크플로우

## 목표

AI-DLC의 3단계 적응형 워크플로우(Inception → Construction → Operations)를 Superpowers의 컴포저블 Skills 아키텍처로 재구현.

## 디렉토리 구조

```
aidlc-pilot/
├── docs/
│   ├── research/       # 조사 및 분석 문서
│   └── plans/          # 구현 계획 문서
└── skills/             # 실제 구현할 Skills (추후)
```
