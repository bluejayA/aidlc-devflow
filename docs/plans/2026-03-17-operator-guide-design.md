# 운영자 가이드 설계

**날짜**: 2026-03-17
**상태**: 설계 승인됨

## 배경

aidlc 플러그인을 설치하여 운영하는 제3자를 위한 운영 매뉴얼. 기술 스택 커스터마이즈, 설계 원칙 조정, 프로젝트 프로파일 설정, 스킬 관리 방법을 안내.

## 파일

- Create: `docs/guide/operator-guide.md`
- 기존 파일 수정 없음

## 구성 (5개 섹션)

### 1. 기술 카탈로그 커스터마이즈
- `_shared/patterns/tech-stack-defaults.md`의 구조 설명
- 기술 추가/제거/우선순위 변경 방법
- 조직의 기술 표준에 맞게 조정하는 예시

### 2. 질문 설계 원칙 조정
- `_shared/patterns/question-format-guide.md`의 4가지 원칙 소개
- 조직의 사용자 수준에 맞게 기본 모드(가이드/전문가) 조정
- 선택지 표현을 조직 용어에 맞게 변경하는 방법

### 3. 워크플로우 기본값 설정
- `devflow-conventions.md`에서 운영자가 조정 가능한 항목 목록
- TDD 필수/선택, 리뷰 depth 기본값, 서브에이전트 모델 선택 등
- 조직 정책에 따른 설정 예시

### 4. 프로젝트 프로파일
- 새 프로젝트 시작 시 사전 설정 방법 (CLAUDE.md 또는 프로젝트별 설정)
- 예시: "이 프로젝트는 Python+FastAPI, TDD 필수, Minimal depth"
- 프로파일이 워크플로우에 어떻게 반영되는지 흐름 설명

### 5. 스킬 추가/수정
- 새 스킬 추가 시 참조할 문서 맵 (best-practices → pattern-catalog → writing-skills)
- 기존 스킬 수정 시 영향 범위 확인 방법
- skill-reviewer로 검증하는 방법

## 원칙

- 독자는 제3자 — aidlc 내부 구조를 모르는 사람도 따라할 수 있어야 함
- 각 섹션은 "무엇을, 어디서, 어떻게" 구조로 작성
- 운영에 필요한 최소한의 정보만 (내부 구현 상세 불필요)
- 향후 새 패턴/규약 추가 시 이 가이드에 항목 추가 권장
